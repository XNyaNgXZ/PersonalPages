# PersonalPages - веб-система для создания персональных страниц.

Курсовой проект на C#.

PersonalPages - веб-приложение, в котором пользователь может быстро собрать свою персональную страницу: добавить аватар, заголовк, описание и кнопки-ссылки на соцсети, выбрать тему оформления и получить короткую публичную ссылку вида '/p/name'.

## Возможности 

- Регистрация и вход пользователя.
- Конструктор страницы из блоков: заголовок, текст, изображение, ссылка.
- Изменение порядка блоков.
- Темы оформления страницы.
- Публичная страница по короткой ссылке.
- Доп. функции: аватар, счетчик просмотров, QR-код.

## Технологии

С# - .NET
ASP.NET Core MVC - Веб-фреймворк
Entity Framework Core - Работа с базой данных
SQLite - База данных
Razor, Bootstrap, CSS - Интерфейс
